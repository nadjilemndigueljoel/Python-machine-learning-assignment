## Part C: Theory Questions

1. What is the Supervised Machine Learning?
Supervised Machine Learning is a type of machine learning where a model learns from data that has inputs and correct answers.

2. What the Unsupervised Machine Learning?
Unsupervised Machine Learning is a type of machine learning where a m odel finds patterns or groups in data without given answers.

3. Explain the difference between supervised and unsupervised learning.

Supervised learning uses labelled data to make prediction. Unsupervised learning uses data without labels to find patterns or groups.

4. Why is Linear Regression considered supervised lerning?

Linear Regression is supervised learning because it learns from study hours and known exam scores to predict new scores.

5. Why is K-Means considered unsupervised learning?

K-Means is unsupervised learning because it groups customer's using their data without knowing their groups in advance.

6. What is the difference between fit() and predict()?

The fit() function trains the model using data. The predict() function uses the trained model to make predictions.
